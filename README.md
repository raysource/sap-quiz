# SD認定試験 過去問クイズ（学生版 / 老师版）

由目录下的 `01_SD認定試験過去問題_日別問題試験.xls` 生成的自测网站，离线可用，无需服务器。

## 两个入口

| 页面 | 用途 | 入口 |
|---|---|---|
| `index.html` | **学生版**：逐题作答，作答过程中**不显示对错**；点「提交并生成总结」后给出分数、逐题结果、错题与解说，再点「导出 PDF 报告」→ 打印对话框选「存储为 PDF」 | 双击即用 |
| `teacher.html` | **老师版**：口令进入，答完即批改，显示原表正解与解说，可「显示本套答案」 | 默认口令 `teacher` |

改口令：`python3 tools/set_password.py 新口令`（只改 `teacher.html` 里的 FNV-1a 校验值，明文不落盘）。

口令校验在浏览器本地完成 —— **只能防误入，防不住翻看源码的人**。要真权限就得放到有服务端的系统里。
老师版登录状态记在 `sessionStorage`，关掉标签页即需要重新登录。

## 内容

- 15 套题 = Excel 的 15 个 sheet：`2日目 … 15日目` / `実力テスト` / `実力テスト (10)`
- 442 题组 / 1720 条陈述（○×判断 1340 条、選択 380 条）
- 分数 = 正确陈述数 ÷ 总陈述数 × 100；**未作答按错误计分**（提交时会先提示还剩几题）
- **PDF 报告**：提交后点「导出 PDF 报告」（或 Cmd+P）。打印媒体下只输出报告——标题、分数与等级、姓名/学号、
  正确陈述/全对题组/已作答/用时/提交时间、逐题结果表、错题与解说（含原表解说）+ 页脚，**不含作答界面与题目卡片**。
  老师版打印则相反：保留题目与答案卡片，方便印讲义。
- 学生版进度与成绩存 localStorage（`sdq.student.v1`），老师版独立存 `sdq.teacher.v1`

## 重新生成 / 验收

```bash
bash tools/run_all.sh            # 解析 Excel -> 模型自检 -> 浏览器 E2E（22 项断言，两版本都跑）
python3 tools/parse_quiz.py      # 只重解析（换 Excel 后跑这个，同时生成 data.js）
node tools/browser_check.mjs     # 只跑浏览器验收（截图 + 样例报告 work/shots/report-4日目.pdf）
python3 tools/set_password.py X  # 改老师版口令
```

## 发布（GitHub）

仓库：**https://github.com/raysource/sap-quiz**（public）· 分支 `main` · 入口 `index.html` / `teacher.html`

```bash
bash tools/publish_to_github.sh "提交信息"   # init（若无）+ remote + commit + push，可反复执行；跑完自动对账
```

仓库里没有：`*.xls` 题库原件（版权，且 1 MB）与 `work/`（解析中间产物 + 验收截图）。
克隆后直接双击 `index.html` 即可用（题目数据在 `data.js`）。

> ⚠️ 学生版的判分与批改全在浏览器本地算，所以**答案必然随学生版一起下发**（`data.js` 里就是全部 ○/×）。
> 公开仓库 = 答案公开，学生版只是「不显示答案」，不是「拿不到答案」；老师版口令同理，只能防误入。
> 要真正不给学生答案，必须加服务端（交卷上传、服务端判分）。

## 数据说明

- 答案与解说（備考）全部取自原 Excel，未改写。
- 判断题的 ○/× 就是该条陈述的对错；选择题的 ○ 是原表选中的答案（题目多为「選べ」），
  所以界面写「原表の答案」而不是「正解」——原表把同一主题的多次出题并在一起时答案可能不止两条。
- 原表 4 条陈述带 `?`/无标注，无法判分，已剔除（脚本会打印条数）。
- `実力テスト (10)` 表尾的「正解数 / 出題キーワード」笔记区不是题目，解析时在表格结束标记处截断。
